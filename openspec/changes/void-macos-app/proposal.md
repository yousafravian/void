# Proposal: Void — Native macOS Clipboard Manager & Productivity Hub (100% Paste for Mac Clone)

## Why

macOS default clipboard behavior overwrites copied items on every `Command-C`, and even macOS 26 Tahoe's built-in Spotlight clipboard history is ephemeral (30 minutes to 7 days), unorganized, and lacks visual cards, pinboards, inside-image OCR search, sequential Paste Stack, rich previews, in-place editing, and Model Context Protocol (MCP) AI integration.

**Paste for Mac** (`pasteapp.io`, Paste 6) sets the gold standard for clipboard managers on macOS with its bottom-sliding Liquid Glass horizontal card drawer, unlimited visual history, color-coded Pinboards, Power Search with OCR and inline smart filters, Jump to History, Direct Paste, Paste Stack, Quick Look & in-place editing with Apple Intelligence Writing Tools, Intelligent Clipboard context-aware suggestions, and built-in local Paste MCP server. However, Paste requires a recurring paid subscription (`$3.99/mo` or `$29.99/yr`) or `$99.99` license.

We are building **Void**, a dedicated, 100% feature-complete and UI/UX-faithful native macOS clone of Paste 6 designed for local personal use, storing all clipboard history, rich assets, OCR indices, and pinboards locally on the user's Mac with zero subscription gates and full privacy.

## What Changes

- **Create Native macOS Application (`Void.app`)**: Built with Swift 6, AppKit (`NSPanel`, `NSStatusItem`, `NSPasteboard`, `CGEvent`), and SwiftUI featuring Paste 6's signature **Liquid Glass** aesthetic, Dark/Light mode adaptation, brand accent palette (`#FFB250` Yellow, `#FF9400` Orange, `#101010` Carbon Black), and optional UI sound effects.
- **Implement Bottom Sliding Horizontal Panel & Card Scroller**: Summoned via `Shift-Command-V` or the menu bar status icon, supporting vertical/horizontal window resizing, Compact Mode, smooth horizontal card scrolling, color-coded card headers derived from source app icons, rich content previews, metadata footers, and full keyboard navigation.
- **Implement Universal Clipboard Capture Engine**: Background polling/monitoring of `NSPasteboard.general` capturing Plain Text, Rich Text (`RTF`/`HTML`), Source Code, Links/URLs (with `LinkPresentation` titles, OpenGraph metadata, and thumbnails), Images (with dimensions and asynchronous `Vision` framework OCR text recognition), Files & Folders (Finder URLs, icons, sizes, multi-file support), and Colors (6-char HEX / RGB swatches). Includes Continuity Camera import, manual item creation (`Command-N`), privacy filtering for confidential/transient pasteboard markers (`org.nspasteboard.ConcealedType`, `TransientType`, `AutoGeneratedType`), excluded applications list, and timed Pause Capture (`Command-T`: 15m, 30m, 1h, or manual resume).
- **Implement Pinboards & Organization**: Top-bar pinboard tabs next to Clipboard History with create (`Shift-Command-N`), rename, color-code, reorder, and delete actions; single-pinboard-per-item semantics while keeping items in Clipboard History; drag-and-drop pinning and card reordering; multi-select (`Command-Click`, `Shift-Click`, `Command-A`) bulk actions; retention immunity for pinned items; and local Pinboard JSON/archive export & import (replacing cloud-only Shared Pinboards for local workflows).
- **Implement Power Search, OCR & Smart Filters**: Instant type-to-search or `Command-F` activation, SQLite FTS5 full-text search across content, custom labels, URLs, source apps, and OCR text inside images (with matched text highlighting), second `Command-F` filter bar expansion, inline smart filter chips (`Content Type`, `Source App`, `Date Range`, `Pinboard`), inline filter suggestions, and **Jump to History** (`Command-G` / `Show in Clipboard` or `Show in <Pinboard>`).
- **Implement Pasting & Paste Stack Mechanics**: Direct Paste (`Return` / double-click) into the active application using macOS Accessibility (`AXIsProcessTrusted` + `CGEvent` `Command-V`) with automatic fallback to copying to `NSPasteboard`; Paste as Plain Text (`Shift-Return` with configurable modifier or global `"Always paste as Plain Text"` toggle); Quick Paste (`Command-1` … `Command-9` and `Shift-Command-1` … `9`); drag-and-drop or paste images directly as files; Open Link/File (`Command-O`) and `Reveal in Finder`; and floating **Paste Stack** (`Shift-Command-C`) with FIFO/LIFO order toggle, Plain Text toggle, pause toggle, and swipe-to-delete.
- **Implement Quick Look Preview, In-Place Editing & Writing Tools**: `Space` bar preview overlay supporting scrollable text/syntax-highlighted code (with character/word/line counts), interactive `WKWebView` link preview, image viewer with Rotate and Extract Text (OCR), media/PDF preview, and interactive Color Picker. Supports in-place editing (`Command-E`), item renaming/labeling (`Command-R`), and native macOS **Apple Intelligence Writing Tools** integration (`Proofread`, `Rewrite`, `Friendly`, `Professional`, `Concise`, `Summarize`, `Compose`).
- **Implement Intelligent Clipboard & Local Void MCP Server**: On-device context-aware `Suggestions` tab recommending relevant clipboard items for the active app, plus a built-in local **Model Context Protocol (MCP)** server (`http://127.0.0.1:39725/mcp` with bearer token + stdio bridge) exposing tools to search history, read items, create items, and manage pinboards. Includes `Settings -> Intelligence / MCP & AI Tools` connection wizard and approval manager for Claude Desktop, Claude Code, Codex, Cursor, VS Code, Windsurf, and Custom MCP clients.
- **Implement Settings, Retention Engine & System Integration**: Multi-tab Settings window (`General`, `Privacy`, `Shortcuts`, `Intelligence / MCP & AI Tools`, `Sync & Backup`), configurable history retention (`1 Day`, `1 Week`, `1 Month`, `1 Year`, `Forever`) with `Erase History…`, screen-sharing privacy (`Show during screen sharing` toggle via `NSWindow.SharingType`), undo support (`Command-Z`), and macOS **App Intents / Shortcuts** actions.

## Capabilities

### New Capabilities
- `ui-shell-and-panel`: Bottom-anchored Liquid Glass sliding panel (`NSPanel`), resizable and compact modes, menu bar status item and pause menu, color-coded horizontal card scroller, and full keyboard navigation.
- `clipboard-capture-engine`: Background `NSPasteboard` monitoring for text, RTF/HTML, code, links, images (with Vision OCR), files/folders, and colors; Continuity Camera support; manual item creation (`Command-N`); confidential/transient filtering; excluded apps; and timed pause capture (`Command-T`).
- `pinboards-and-organization`: Custom color-coded pinboards, tab bar navigation, drag-and-drop pinning and card reordering, multi-select bulk actions, retention immunity, and local pinboard export/import.
- `power-search-and-filters`: Instant full-text and inside-image OCR search, inline smart filter chips (type, source app, date, pinboard), filter bar (`Command-F`), and Jump to History (`Command-G`).
- `pasting-and-paste-stack`: Direct Paste to active app via Accessibility (`CGEvent`), clipboard fallback, Paste as Plain Text (`Shift-Return`), Quick Paste (`Command-1`–`9`), drag-and-drop images as files, and Paste Stack (`Shift-Command-C`) sequential queue.
- `item-preview-and-editing`: Quick Look (`Space`) rich preview for text/code/web/images/files/colors, in-place text/URL editing (`Command-E`), custom item renaming (`Command-R`), image rotation & OCR extraction, interactive color picker, and Apple Intelligence Writing Tools.
- `intelligent-clipboard-and-mcp`: Context-aware Intelligent Clipboard suggestions and built-in local MCP server (`127.0.0.1:39725/mcp` + stdio) with per-client approval and setup guides for Claude Desktop, Claude Code, Codex, Cursor, VS Code, Windsurf, and Custom MCP tools.
- `settings-storage-and-shortcuts`: Local SQLite + FTS5 database and asset storage in `~/Library/Application Support/Void/`, retention policy engine, multi-tab Settings UI, customizable global shortcuts and modifiers, Undo (`Command-Z`), and macOS Shortcuts App Intents.

## Impact

- **New Codebase**: Creates a native macOS Xcode / Swift Package project in `/Users/yousafraza/development/void` targeting macOS 15.0+ (with macOS 26 Liquid Glass & Apple Intelligence enhancements).
- **System Permissions**: Requires user-granted Accessibility permission (`AXIsProcessTrusted`) for Direct Paste and Paste Stack `Command-V` interception, optional Screen Recording / Accessibility context permission for Intelligent Clipboard suggestions, and local network / localhost socket binding (`127.0.0.1:39725`) when Void MCP is enabled.
- **Local Storage**: Stores SQLite + FTS5 database and media blobs in `~/Library/Application Support/Void/` with zero external telemetry or third-party cloud dependencies.
