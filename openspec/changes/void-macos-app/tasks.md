# Tasks: Void — Native macOS Clipboard Manager (Paste 6 Clone)

## 1. Project Scaffolding & Local Storage Layer (`settings-storage-and-shortcuts`)

- [x] 1.1 Create native macOS Swift 6 / Xcode application target (`Void.app`) and companion `void-mcp` CLI target targeting macOS 15.0+ with macOS 26 Liquid Glass support, bundle ID `com.voidapp.mac`, and required entitlements (`App Sandbox` disabled or configured for Accessibility, `CGEvent`, and localhost MCP server).
- [x] 1.2 Implement `AssetStore` (`~/Library/Application Support/Void/Assets/`) with SHA-256 content-addressed storage, retina image thumbnail generation, and unreferenced blob garbage collection.
- [x] 1.3 Implement `DatabaseManager` (`~/Library/Application Support/Void/Void.sqlite`) using WAL mode with schema migrations for `clipboard_items`, `pinboards`, `clipboard_items_fts` (SQLite FTS5), and `mcp_clients`.
- [x] 1.4 Implement `RetentionService` supporting `Day`, `Week`, `Month` (default), `Year`, and `Forever` cleanup schedules plus `Erase History…` while guaranteeing 100% retention immunity for pinned items.
- [x] 1.5 Implement `UndoManagerService` supporting `Command-Z` undo for item deletions, renames, in-place edits, and pinboard removals.

## 2. Clipboard Capture Engine & Privacy Filters (`clipboard-capture-engine`)

- [x] 2.1 Implement `PasteboardMonitor` polling `NSPasteboard.general.changeCount` every 200ms with consecutive duplicate detection (updating `last_copied_at` and moving existing item to front).
- [x] 2.2 Implement privacy and exclusion filtering: detect `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType`, `org.nspasteboard.AutoGeneratedType`, and password-manager markers; filter against `Ignore Applications` bundle IDs (pre-populated with `com.apple.Passwords`); and support timed/manual Pause (`Command-T`: `15m`, `30m`, `1h`, `Resume`).
- [x] 2.3 Implement multi-format payload extractors and classifiers for `Text` (Plain Text, RTF, HTML), `Code` (UTI & syntax heuristic detection), `Link` (valid `http`/`https` URLs), `Image` (PNG/TIFF/JPEG/HEIC with `W × H` and byte size), `File` (single and multiple Finder file/folder URLs with icons and byte sizes), and `Color` (standalone 6-char HEX and `rgb()`/`hsl()` color parsing).
- [x] 2.4 Implement `AppIconColorExtractor` to sample and cache the dominant brand color from each source application's icon (`NSWorkspace.shared.icon(forFile:)`).
- [x] 2.5 Implement `LinkMetadataService` using `LPMetadataProvider` and OpenGraph HTML fallback to asynchronously fetch page titles, favicons, and preview thumbnails when `"Generate link previews"` is enabled.
- [x] 2.6 Implement `VisionOCRService` using `VNRecognizeTextRequest` (`.accurate` recognition level) to asynchronously extract and index text and normalized bounding boxes from copied images and screenshots.
- [x] 2.7 Implement manual item creation (`Command-N` / `New Text Item`) and macOS Continuity Camera responder integration (`Take Photo` / `Scan Documents` from iPhone or iPad).

- [x] 3.2 Implement vertical window resizing via top-edge drag handle and Compact Mode toggle, persisting panel height in `UserDefaults`.

- [x] 3.4 Build `ClipboardCardView` matching Paste 6's Liquid Glass card anatomy: source-app color-coded header bar, app icon on the right, item title/type and relative timestamp (`just now`, `3m`, `2h`, `yesterday`) on the left, type-specific content body (styled text, syntax-highlighted code, link preview card, image thumbnail, file icon list, or full-bleed color swatch), and footer metadata (`characters`, `W × H`, HEX code, file size, pinboard color dot, and `⌘1`–`⌘9` Quick Paste badge).
- [x] 3.5 Implement horizontal card scroller (`ScrollViewReader` + `LazyHStack`) and full keyboard navigation (`←`, `→`, `Command-↑` first item, `Command-↓` last item, `Shift-←`/`→` extend selection, `Command-A` select all, `Command-Click` / `Shift-Click` multi-select, `Escape` dismiss).

## 5. Power Search, OCR Highlighting & Smart Filters (`power-search-and-filters`)

- [x] 5.1 Implement instant type-to-search in `VoidPanel` and `Command-F` search activation, with a second `Command-F` expanding the full filter bar and `Tab` switching focus between the search bar and card results.
- [x] 5.2 Connect Power Search to SQLite FTS5 (`clipboard_items_fts`) to search item text, custom titles, URLs, filenames, source app names, and inside-image Vision OCR text in real time, highlighting matched text regions on text and image cards.
- [x] 5.3 Implement inline smart filter chips and autocomplete suggestions for `Content Type` (`Text`, `Link`, `Image`, `File`, `Color`, `Code`), `Source App`, `Date Range` (`Today`, `Yesterday`, `Last 7 Days`, `Last Week`, `Last Month`), and `Pinboard Filters` (single or multi-pinboard selection).
- [x] 5.4 Implement `Jump to History` (`Command-G` and context menu `Show in Clipboard` / `Show in <Pinboard>`) to exit search, switch to the target list, and scroll directly to the item's chronological neighbors.

## 6. Direct Paste, Quick Paste & Paste Stack (`pasting-and-paste-stack`)

- [x] 6.2 Implement Paste as Plain Text via `Shift-Return` (using configurable Plain Text modifier), `Shift-Command-1`–`9`, context menu `Paste as Plain Text`, and global `"Always paste as Plain Text"` setting.
- [x] 6.3 Implement Quick Paste numbered shortcuts (`Command-1` through `Command-9` with configurable Quick Paste modifier) and multi-select bulk paste.
- [x] 6.4 Implement drag-and-drop from cards to external apps and `NSFilePromiseProvider` / temporary `.png` file materialization so `Image` cards can be dragged or pasted directly as files into Finder or browser file uploads.
- [x] 6.5 Implement `Command-O` (`Open` link in default browser or file in default/chosen app) and `Reveal in Finder` for file cards.
- [x] 6.6 Implement floating `PasteStackPanel` (`Shift-Command-C`) that queues every subsequent `Command-C` copy, intercepts `Command-V` to paste and pop items sequentially, and provides controls for FIFO/LIFO order direction toggle, Plain Text (`T`) toggle, Pause/Resume stack capture, and two-finger swipe-left / context menu item deletion.
