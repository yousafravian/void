# Void

**Your Mac’s Infinite, Intelligent Clipboard.**

Void is a native macOS 14+ clipboard manager built with Swift, AppKit, SwiftUI, and SQLite FTS5. It features an edge-anchored, non-activating sliding dock (`⇧⌘V`), on-device **Apple Vision OCR**, a sequential **Paste Stack** (`⇧⌘C`), color-coded **Pinboards**, and a built-in **Model Context Protocol (`void-mcp`)** server for AI coding agents.

---

## ✨ Features

### 1. Edge-Anchored Non-Activating Dock (`⇧⌘V`)
- Built on a custom AppKit `NSPanel` (`.nonactivatingPanel`, `.statusBar` level, `.canJoinAllSpaces`, `.fullScreenAuxiliary`) with native `NSVisualEffectView` vibrancy.
- Summoning Void never steals keyboard focus from your active editor, terminal, or browser.
- **Direct Auto-Paste**: Double-click any card, press `Return`, or press `⌘1`–`⌘9` to immediately paste into the frontmost application (`⌘⇧Return` pastes as plain text).
- Supports **Bottom**, **Top**, **Left**, and **Right** screen edge docking.

### 2. Automatic Rich Capture & Classification
- Polls `NSPasteboard.general.changeCount` at 250ms intervals with zero background CPU overhead when idle.
- Automatically classifies items into **Text**, **Code**, **Link**, **Image**, **Color**, and **File**:
  - **Code Detection**: Heuristic language detection (Swift, Python, TypeScript/JavaScript, Rust, Go, SQL, JSON, Shell, HTML/CSS).
  - **Color Swatches**: Detects `#HEX`, `rgb()`, `rgba()`, and `hsl()` values and renders a live color preview on the card.
  - **Rich Link Previews**: Asynchronously fetches page titles and OpenGraph metadata via `LPMetadataProvider`.
  - **App Attribution**: Records the source application's name, bundle ID, icon, and dominant brand color.
  - **Content Deduplication**: Computes SHA-256 hashes (`contentHash`) so re-copying an existing item promotes it to the top instead of creating duplicates.

### 3. On-Device Apple Vision OCR
- Every copied image or screenshot is processed asynchronously in the background using `VNRecognizeTextRequest` (`.accurate` recognition level).
- Extracted text is indexed directly in SQLite FTS5—search for text inside a screenshot and copy or paste it immediately.

### 4. Sub-Millisecond Search (`SQLite FTS5`)
- Powered by SQLite3 in `WAL` (Write-Ahead Logging) mode with a virtual `FTS5` full-text index (`porter unicode61` tokenizer).
- Searches across plain text, OCR text, link titles, URLs, file names, and source app names simultaneously.
- Filter by content type (`Text`, `Images`, `Links`, `Files`, `Code`, `Colors`), source application, or Pinboard.

### 5. Sequential Paste Stack (`⇧⌘C`)
- Activate Paste Stack mode and copy multiple snippets in sequence (`⌘C`, `⌘C`, `⌘C`).
- A compact floating HUD tracks your FIFO queue; each `⌘V` pops and pastes the next item in order.
- Configure delimiter joiners (`Newline`, `Space`, `Comma`, or `None`) or drag to reorder items in the queue.

### 6. Pinboards, Quick Look & In-Place Editing
- **Pinboards**: Organize recurring snippets, prompts, and tokens into color-coded Pinboards. Switch boards with `⌘[` / `⌘]`.
- **Quick Look (`Space`)**: Preview high-resolution images, files, and long documents using macOS Quick Look (`QLPreviewView`) or syntax-highlighted text inspection.
- **In-Place Editor (`⌘E`)**: Edit a clipboard item's text or apply built-in transforms (Uppercase, Lowercase, Title Case, Trim Whitespace, Pretty-Print JSON, Strip Formatting) before pasting.

### 7. Built-In MCP Server (`void-mcp`)
- Ships with a companion `void-mcp` CLI binary speaking JSON-RPC 2.0 over `stdio`.
- Gives AI assistants (**Claude Code**, **Claude Desktop**, **Cursor**, **VS Code**) read/write access to your clipboard history and Pinboards.

### 8. Privacy by Default
- **100% Local**: Stored in `~/Library/Application Support/Void/` with no cloud sync or telemetry.
- **Password Manager Protection**: Automatically ignores pasteboard payloads marked with `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType`, or `org.nspasteboard.AutoGeneratedType`.
- **Excluded Apps**: Pre-configured to ignore **1Password**, **Bitwarden**, **Keychain Access**, **KeePassXC**, **LastPass**, and **Dashlane**, with custom bundle ID exclusions in Settings.

## 🛠️ Tech Stack & Architecture

| Layer | Technology |
| :--- | :--- |
| **Language & Target** | Swift 5.10, macOS 14.0+ (`Sonoma` / `Sequoia`) |
| **Windowing & Shell** | AppKit (`NSPanel`, `NSStatusItem`, `NSVisualEffectView`) + SwiftUI |
| **Storage & Search** | SQLite3 (`WAL` mode + `FTS5` full-text index) + SHA-256 content-addressed `Assets/` blob store |
| **System Frameworks** | `Vision` (OCR), `LinkPresentation` (URL previews), `QuickLookUI`, `Carbon` (global hotkeys), `AppIntents` (Shortcuts/Siri) |
| **Auto-Paste Engine** | `NSApp.yieldActivation(to:)` + `CGEvent` (`kCGHIDEventTap`) synthetic `⌘V` dispatch |
| **AI Integration** | `void-mcp` JSON-RPC 2.0 `stdio` server |

## 🚀 Getting Started

### Prerequisites
- **macOS 14.0 (Sonoma)** or later
- **Xcode 15.4+** or **Swift 5.10+** Command Line Tools

### Build & Run

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yousafravian/void.git
   cd void
   ```

2. **Build and package `build/Void.app`**:
   ```bash
   make build
   ```
   This compiles both `Void` and `void-mcp`, bundles them inside `build/Void.app/Contents/MacOS/`, and applies an ad-hoc code signature.

3. **Launch Void**:
   ```bash
   make run
   # Or directly:
   open build/Void.app
   ```

4. **Enable Direct Auto-Paste (Accessibility Permission)**:
   - To let Void automatically trigger `⌘V` in your active text field on `Return` or double-click, grant Accessibility access in **System Settings → Privacy & Security → Accessibility** (or click the **Enable Auto-Paste** pill inside the Void dock header).
   - If you rebuild the binary and macOS caches an old signature, reset the TCC entry with:
     ```bash
     tccutil reset Accessibility com.voidapp.mac
     ```

### Running Tests

Run the XCTest suite covering SQLite FTS5 indexing, deduplication, payload classification, Paste Stack FIFO queuing, and MCP JSON-RPC tool execution:

```bash
make test
```

## 🤖 MCP Server (`void-mcp`) Setup

The `void-mcp` binary is bundled inside `build/Void.app/Contents/MacOS/void-mcp` and reads/writes the shared SQLite database at `~/Library/Application Support/Void/void.sqlite`.

> **Note:** Enable the MCP server toggle in **Void Settings → MCP Server** before connecting an AI client.

### Claude Code
```bash
claude mcp add void "/ABSOLUTE/PATH/TO/void/build/Void.app/Contents/MacOS/void-mcp"
```

### Claude Desktop / Cursor (`mcp.json`)
```json
{
  "mcpServers": {
    "void": {
      "command": "/ABSOLUTE/PATH/TO/void/build/Void.app/Contents/MacOS/void-mcp",
      "args": []
    }
  }
}
```

### Available MCP Tools

| Tool Name | Description |
| :--- | :--- |
| `search_clipboard` | Full-text FTS5 search across clipboard history (`query`, optional `type` filter, `limit`). |
| `get_recent_items` | Retrieve the most recently copied clipboard items (`limit`). |
| `get_pinboard_items` | List all items saved to a specific Pinboard (`pinboard_name`). |
| `create_clipboard_item` | Copy a new text/code snippet to the system clipboard and save it to Void (`text`, optional `title`, `pinboard_name`). |
| `pin_item_to_pinboard` | Assign an existing clipboard item UUID to a named Pinboard (`item_id`, `pinboard_name`). |
